# RadPraktik

Web app belajar interaktif Teknik Radiografi 1: materi per modul, latihan soal pilihan ganda, dan contoh kasus acak. Disusun dari **Modul Praktek Laboratorium Teknik Radiografi 1, Jurusan Teknik Radiodiagnostik dan Radioterapi, Poltekkes Kemenkes Semarang**.

- Live (target): https://radpraktik.rindia.my.id
- Untuk agent/kontributor: mulai dari [`AGENTS.md`](AGENTS.md)
- Rencana lengkap: [`docs/PLAN.md`](docs/PLAN.md) · Progres: [`docs/TASKS.md`](docs/TASKS.md)

## Isi
- 24 modul dalam 5 region (Dasar, Ekstremitas Atas, Ekstremitas Bawah, Pelvis, Vertebra)
- 10 soal latihan per modul (240 soal)
- 30 contoh kasus acak dengan tebakan bertahap (proyeksi → posisi/arah sinar → pembahasan)
- Progres tersimpan di perangkat, tanpa login
